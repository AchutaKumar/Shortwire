Getting a network error?
If Django is serving this page (the normal setup), leave SERVER ADDRESS blank — requests go to the same origin and no CORS setup is needed. Only fill in an address (e.g. http://localhost:8000) if you opened this file directly from disk or are hosting it somewhere else — in that case install django-cors-headers, add it to INSTALLED_APPS and MIDDLEWARE, and set CORS_ALLOW_ALL_ORIGINS = True in your dev settings.
